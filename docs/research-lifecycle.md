# Research lifecycle

The organization uses a six-stage, evidence-bearing lifecycle:

1. **Explore:** bound the question, sources, assumptions, risks, and unknowns.
2. **Cover/plan:** decompose the work into declared contexts and pairwise
   overlap contracts.
3. **Execute:** produce outputs inside each context without changing the
   declared interfaces silently.
4. **Verify:** run deterministic checks, bind evidence by content hash, and
   identify stale claims or decisions.
5. **Glue:** combine only compatible context results and record why the cover
   is coherent.
6. **Project:** create traceable artifact manifests for papers, proposals,
   code, or datasets.

History is append-oriented; active truth is an explicit state, not whatever an
agent most recently said. Generated context belongs under a repository-owned
generated directory with generator version and source hashes. It cannot
replace hand-authored policy without an explicit reviewed operation.
