# Historical name migrations

This file is historical evidence, not an active or planned repository list.

- `asc-research-os` was a provisional name for the role now canonically owned
  by `asc-os`. No repository existed to rename during the 2026 reorganization.
- `asc-xde-py` was a provisional candidate name for a possible Python PDE
  layer. It was absent and was not created or renamed. The approved future
  neural-operator boundary is `asc-no`, with implementation deferred.
- `asc-mathcopilot` is a removed proposal and was absent during the audit.
- `asc-lab` is a removed legacy repository that existed during the audit. It
  was preserved without deletion, transfer, rename, or automatic archival and
  is intentionally absent from active/planned architecture lists.

Canonical naming changes require identity verification, repository-ID and
history preservation, redirect/reference audits, and an explicit rollback
record. A duplicate repository or copied history is not an acceptable rename.
