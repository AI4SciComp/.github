# Security policy

Please report vulnerabilities privately with GitHub's security-advisory form
for the affected public repository. If no advisory form is available, contact
the organization owner through GitHub without publishing exploit details.

Include the affected repository and commit, minimal reproduction, impact, and
suggested mitigation. Do not include live credentials or sensitive research
data. Public issues are appropriate for hardening ideas only when they do not
disclose an exploitable vulnerability.

AI4SciComp does not ask reporters to create repository secrets. Research tools
must treat arbitrary execution, credential access, network retrieval, and
filesystem escape as explicit capabilities rather than implicit conveniences.
